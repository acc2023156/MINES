# Mines — 5×5 踩地雷下注遊戲（模擬版，RTP 98%）

**線上試玩：https://acc2023156.github.io/MINES/**

> 本專案使用**模擬遊戲幣**，不涉及真實金錢，僅供遊戲開發與演示。

## 玩法

1. 選下注金額與地雷數（1–24），按「下注」。
2. 25 格中藏有指定數量的地雷 💣，其餘為寶石 💎。
3. 每翻開一顆寶石倍數上升；翻到地雷輸掉本局下注。
4. 翻開至少一格後可隨時「兌現」，派彩 = 下注 × 目前倍數；寶石全翻完自動兌現。

## 數學（RTP 98%）

- 連續翻開 k 格皆為寶石的機率：`P(m, k) = C(25−m, k) / C(25, k)`
- 倍數：`multiplier(m, k) = 0.98 / P(m, k)`
- 因此**任何**「地雷數 × 翻幾格兌現」的策略，期望回報都是 98%（莊家優勢 2%）。
  「97.7% 勝率」之類的打法只是把勝率換成很低的倍數（例：1 雷翻 1 格勝率 96%、倍數 1.02×），長期回報仍是 98%。
- 派彩向下取整到 0.01。

| 地雷 | 翻 1 格 | 翻 3 格 | 翻 5 格 |
|---|---|---|---|
| 1 | 1.02× (96%) | 1.11× (88%) | 1.22× (80%) |
| 3 | 1.11× (88%) | 1.46× (67%) | 1.98× (50%) |
| 5 | 1.22× (80%) | 1.98× (50%) | 3.36× (29%) |
| 24 | 24.50× (4%) | – | – |

## 公平性（Provably Fair）

- 每局開始前公開 `SHA256(serverSeed)`，結束後公開 serverSeed。
- 亂數：`SHA256(serverSeed:clientSeed:nonce:cursor)` 每 8 個 hex 轉成一個 0~1 浮點數。
- 對 0–24 做 Fisher–Yates 洗牌，前 m 格為地雷。
- 頁面「公平性」視窗可輸入任一局的種子重新計算地雷位置；客戶種子可自行修改。

## 功能

| 項目 | 說明 |
|---|---|
| 手動 | 下注、翻格、隨機翻一格、兌現；空白鍵下注／兌現，R 隨機翻格 |
| 自動 | 在盤面預選格子，設定局數、贏／輸後加碼 %、獲利／虧損停止 |
| 資訊 | 下一格勝率、下一格倍數、目前倍數與獲利、倍數階梯、完整倍數表 |
| 紀錄 | 最近 100 局、勝率、淨損益、實際回報率；存在 localStorage，重新整理會還原進行中的局 |
| 大廳 | 網址帶 `?return=<大廳網址>` 會顯示「‹ 大廳」按鈕（僅接受 acc2023156.github.io 與本機） |
| 自適應 | 手機（≤900px）盤面在上、主按鈕固定在底部 |
